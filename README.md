# ABGFC Tracker

Team stats for Aldershot Boys & Girls FC — coaches enter results from the pitch, the app
derives the rest. Live at <https://abgfc.neuralaspect.com>.

- **Developer documentation**: [`docs/`](docs/README.md) — architecture, data model, API,
  frontend, stats engine, security, deployment, development guide, roadmap.
- **Condensed notes for AI assistants**: [`CLAUDE.md`](CLAUDE.md).

Quick start:

```bash
make install && make seed && make dev
```
